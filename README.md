`# Sistema de Control Escolar

## Descripción

Este proyecto consiste en un sistema básico de control escolar para
administrar información de alumnos, profesores y materias.

El proyecto utiliza PHP como lenguaje de programación, Apache como
servidor web y MariaDB como sistema gestor de base de datos.

## Tecnologías utilizadas

- Linux
- Apache
- PHP
- MariaDB
- Git
- GitHub
